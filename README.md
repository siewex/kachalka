# Тренировочный бот

Приватный Telegram-бот для двоих. Ведёт тренировку в зале:

- показывает упражнение с анимацией, мышцами и подсказками по технике (сворачиваемый блок);
- записывает подходы кнопками или числом в чате;
- держит таймер отдыха и сам присылает следующий подход;
- после упражнения решает, какой вес ставить в следующий раз (без ИИ, по правилам программы);
- хранит историю, рекорды (расчётный 1ПМ) и текущие рабочие веса — у каждого свои.

## Анкета и персональная программа

При первом запуске (или `/survey`) бот задаёт 11 вопросов: пол, возраст, рост, вес, активность, цель
(масса / рельеф / сила), акцент (сбалансированно / ягодицы и ноги / верх тела и руки), опыт, дни в неделю,
время на тренировку и что беспокоит (колени / спина / плечи). По ответам — без ИИ, по правилам:

- **сплит** под число дней и акцент (фулбади, верх/низ, PPL, дни ягодиц) — `bot/planner.py`;
- **упражнения** из каталога с учётом опыта и ограничений, без повторов внутри недели;
- **подходы, повторы, отдых** под цель; число упражнений в день — под время;
- **стартовый вес** в каждом упражнении — от веса тела, пола и опыта (кнопка «Взять N кг»);
- **питание** — калории и БЖУ по Миффлину–Сан Жеору с поправкой на цель;
- **вес тела** — записывается в «📈 Прогресс», по нему пересчитывается питание.

## Готовые программы

| Программа | Схема | Прогрессия |
|---|---|---|
| **Basic Beginner Routine** (r/Fitness) | A: тяга в наклоне, жим лёжа, присед · B: подтягивания, жим стоя, становая. 2×5 + последний на максимум | Все повторы сделаны → +2,5 кг (ноги +5); на максимум больше 10 → двойной шаг; не сделал → −10% |
| **Фулбади A/B** | 5–6 упражнений, 2–3 подхода в диапазоне (6–10, 8–12…) | Все подходы на верх диапазона → +шаг; дважды ниже диапазона → −10% |

Упражнения (58 шт.) лежат в `bot/content/exercises.py`, готовые программы — в `bot/content/programs.py`.
Анимации — бесплатная версия [ExerciseDB](https://github.com/exercisedb/exercisedb-api), только для личного использования:
бот скачивает их сам при первом запуске в `data/media/`.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) и получи токен.
2. `cp .env.example .env`, впиши `BOT_TOKEN`. `ALLOWED_USERS` пока оставь пустым.
3. Запусти бота (ниже), напиши ему что угодно — он ответит твоим Telegram ID. То же самое сделает девушка.
4. Впиши оба ID в `ALLOWED_USERS=111,222` и перезапусти.

### На VPS через Docker

```bash
docker compose up -d --build
docker compose logs -f
```

База и анимации лежат в `./data` — это и есть всё, что нужно бэкапить.

### Локально

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # Linux/macOS: .venv/bin/pip
.venv/Scripts/python -m bot
```

## Тесты

```bash
.venv/Scripts/pip install pytest
.venv/Scripts/python -m pytest
```
